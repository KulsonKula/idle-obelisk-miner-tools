# Idle Obelisk Miner Tools

Calculators for Idle Obelisk Miner. Unofficial, not affiliated with the game's developers.

## Tools

- **Frogger Gem Rate** - net gems per hour for each Frogger grade, so you can see at which grade it starts paying for its own fuel.

## Usage

Export your stats from the game and paste the JSON into the sidebar. The inputs fill in from it. A few values aren't in the export (like D20 charges), so set those by hand.

## Running locally

```
pip install -r requirements.txt
streamlit run app.py
```
